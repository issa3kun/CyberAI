CYBERAI | Windows PowerShell demo

In VS Code, open the extracted cyberai-risk-engine folder that contains
rae_api.py. Start each of the three PowerShell tabs in that folder.

FIRST RUN | INSTALL RAE DEPENDENCIES
python -m pip install -r requirements-n8n.txt

1. TERMINAL 1 | START n8n AND THE RAE
Open Docker Desktop. Run these lines if the services are stopped.
docker start cyberai-n8n
$env:CYBERAI_RAE_API_TOKEN = [Environment]::GetEnvironmentVariable('CYBERAI_RAE_API_TOKEN', 'User')
python rae_api.py --host 0.0.0.0 --port 5001
Leave the updated rae_api.py running on port 5001.

2. TERMINAL 2 | START ZIYAD'S SCANNER
Run from the project folder. Leave the scanner running on port 5000.
Set-Location .\cyberai-api-backend
# Run these two lines once after extracting the ZIP.
python -m venv .venv-local
.\.venv-local\Scripts\python.exe -m pip install -r requirements.txt

$env:CYBERAI_N8N_SCAN_WEBHOOK_URL = 'http://localhost:5678/webhook/cyberai-scanner-intake'
.\.venv-local\Scripts\python.exe -m flask --app ziyad_app:app run --port 5000

3. TERMINAL 3 | RUN A LIVE SCAN AND OPEN THE RESULT
With terminals 1 and 2 running, paste these lines. Change the URL on line 1 to scan another site.
$body = @{url = 'https://example.com'} | ConvertTo-Json -Compress
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:5000/api/scan' -ContentType 'application/json' -Body $body | ConvertTo-Json -Depth 20
Invoke-Item .\rae-exports

PowerShell shows the scanner's findings. Sort rae-exports by Date modified and
open the new cyberai-assessment-*.json for the RAE result. It contains the same JSON the RAE sends to n8n.
To show the workflow, open http://localhost:5678 > CyberAI Scanner to RAE - Local Prototype
> Executions > newest run > Assess scan with RAE.

SAY THIS DURING THE DEMO
"Ziyad's scanner collects evidence. n8n passes it to my RAE, which assesses
it for visitors and website owners. The RAE saves its JSON on my laptop for Bryan."
For a manual handoff, use the new file in rae-exports. Bryan's automatic delivery
settings depend on the webhook format he confirms.

OPTIONAL | TERMINAL 3 — REPLAY A SAVED SCAN
Keep n8n and terminal 1 running. From the project folder, run these three lines.
$env:CYBERAI_N8N_SCAN_WEBHOOK_URL = 'http://localhost:5678/webhook/cyberai-scanner-intake'
$demoId = 'demo-' + (Get-Date -Format 'yyyyMMdd-HHmmss-fff')
$receipt = '.\' + $demoId + '-receipt.json'

Pick one command below. Rerun the three setup lines for each new replay.

A. Synthetic scan with a response
python send_scan.py .\fixtures\synthetic_completed_response.json --input-origin synthetic_test_data --scan-id $demoId --output $receipt

B. Synthetic timeout
python send_scan.py .\fixtures\synthetic_timeout.json --input-origin synthetic_test_data --scan-id $demoId --output $receipt

C. Ziyad's saved scan (place ziyad_scan.json beside send_scan.py)
python send_scan.py .\ziyad_scan.json --input-origin user_supplied_scan --scan-id $demoId --output $receipt

The receipt records delivery. The RAE also saves its assessment in rae-exports.
To show the scan status from the receipt, run this in terminal 3.
(Get-Content $receipt -Raw -Encoding UTF8 | ConvertFrom-Json).response.assessment.scan.status
The timeout demo shows failed even when the webhook returns HTTP 200.
