CYBERAI | Windows PowerShell demo and Git commands

OPEN THREE POWERSHELL TABS IN VS CODE
Terminal 1 starts n8n and the RAE. Leave it running on port 5001.
Terminal 2 starts Ziyad's scanner. Leave it running on port 5000 for live scans.
Terminal 3 sends demo requests, reads receipts, and runs Git.

Run this line in each idle tab to start in the project folder.
Set-Location -LiteralPath 'C:\Users\Acer\Desktop\Major Project\Risk Assessment Engine\CyberAI_Risk_Engine_Stage_2\cyberai-risk-engine'

1. TERMINAL 1 | START N8N AND THE RAE
Open Docker Desktop and wait for its engine. Run these lines in terminal 1.
docker start cyberai-n8n
$env:CYBERAI_RAE_API_TOKEN = [Environment]::GetEnvironmentVariable('CYBERAI_RAE_API_TOKEN', 'User')
python rae_api.py --host 0.0.0.0 --port 5001

When terminal 1 says the RAE is running on port 5001, leave it open.
If your RAE is already running there, go straight to section 2 for a live scan
or section 4 for a replay. If only n8n is stopped, run docker start cyberai-n8n
in terminal 3 after opening Docker Desktop. Check the intake workflow is published.

2. TERMINAL 2 | START THE LIVE SCANNER
From the project folder in terminal 2, run these lines once per session.
Set-Location .\cyberai-api-backend
$env:CYBERAI_N8N_SCAN_WEBHOOK_URL = 'http://localhost:5678/webhook/cyberai-scanner-intake'
.\.venv-local\Scripts\python.exe -m flask --app ziyad_app:app run --port 5000

Wait for "Serving Flask app 'ziyad_app:app'" and port 5000. Leave terminal 2 open.

3. TERMINAL 3 | SEND A LIVE SCAN
With terminals 1 and 2 running, paste these three lines into terminal 3.
To scan a different site, change $targetUrl and rerun all three lines.
$targetUrl = 'https://example.com'
$scanBody = @{url = $targetUrl} | ConvertTo-Json -Compress
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:5000/api/scan' -ContentType 'application/json' -Body $scanBody | ConvertTo-Json -Depth 20

IN YOUR BROWSER | VERIFY THE ASSESSMENT
Open http://localhost:5678 > CyberAI Scanner to RAE - Local Prototype > Executions.
Open the newest run. Receive scanner result shows the URL at body.scan_result.url.
Assess scan with RAE shows assessment.scan.url and assessment.scan.status.
If you published Make Bryan JSON, open that node > Output > Binary > Download.
That file contains the full RAE payload for Bryan, including reporting instructions.

4. TERMINAL 3 | REPLAY A SAVED SCAN
Keep n8n and terminal 1 running. Do this from the project folder in terminal 3.
Run these three lines before each replay to make a fresh receipt filename.
$env:CYBERAI_N8N_SCAN_WEBHOOK_URL = 'http://localhost:5678/webhook/cyberai-scanner-intake'
$demoId = 'demo-' + (Get-Date -Format 'yyyyMMdd-HHmmss-fff')
$receipt = '.\' + $demoId + '-receipt.json'

Choose one case in terminal 3. Run its second line after the sender reports HTTP 200.

4A. TERMINAL 3 | SAVED SYNTHETIC SCAN
python send_scan.py .\fixtures\synthetic_completed_response.json --input-origin synthetic_test_data --scan-id $demoId --output $receipt
Get-Content $receipt -Raw

4B. TERMINAL 3 | SAVED SYNTHETIC TIMEOUT
python send_scan.py .\fixtures\synthetic_timeout.json --input-origin synthetic_test_data --scan-id $demoId --output $receipt
(Get-Content $receipt -Raw | ConvertFrom-Json).response.assessment.scan.status

Expect "failed" for the website check. HTTP 200 means n8n returned the assessment.

4C. TERMINAL 3 | ZIYAD'S SAVED SCAN
Save the full scanner JSON as ziyad_scan.json beside send_scan.py first.
python send_scan.py .\ziyad_scan.json --input-origin user_supplied_scan --scan-id $demoId --output $receipt
Get-Content $receipt -Raw

WHAT TO SAY IN THE DEMO
"In the live demo, PowerShell sends a URL to Ziyad's scanner. In the replay, I
send saved checks and findings. Both go through n8n to my Risk Assessment
Engine, which assesses the evidence for visitors and website owners. The
receipt's response field is the full assessment payload for Bryan's LLM."

5. TERMINAL 3 | COMMIT AND PUSH THIS NOTES FILE
Save the updated CyberAI_PowerShell_Commands.txt in the project folder beside
rae_api.py, replacing your old copy. Run the first line in terminal 3 from
that same folder. Check that Git shows main and any merge is finished, then
run the remaining lines one at a time.
git status --short --branch
git add -- CyberAI_PowerShell_Commands.txt
git --no-pager diff --cached --stat -- CyberAI_PowerShell_Commands.txt
git commit -m "Clarify CyberAI demo terminal steps" -- CyberAI_PowerShell_Commands.txt
git push -u origin main

Refresh https://github.com/issa3kun/CyberAI and open the notes on main.
If Git says "fetch first" and your working tree is clean, run
git pull --no-rebase --no-edit origin main
in terminal 3. Retry the push once the merge succeeds.

    [Environment]::SetEnvironmentVariable('CYBERAI_RAE_API_TOKEN', $env:CYBERAI_RAE_API_TOKEN, 'User')
